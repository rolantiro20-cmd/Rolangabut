# Dynamic Island untuk Windows

Fase 1: island di atas layar, menampilkan lagu yang sedang diputar (Spotify, YouTube di browser, dll.), album art, progress, dan tombol prev / play-pause / next.

- Arahkan mouse ke island untuk membuka.
- Klik kanan island, lalu pilih Keluar untuk menutup.

Build otomatis lewat GitHub Actions. Hasilnya ada di tab Releases (DynamicIsland.exe).
